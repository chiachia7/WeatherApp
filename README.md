# Weather App ☀️🌧️
HTML,CSS,JavaScript

This is a simple weather checking app built with HTML, CSS, and JavaScript.  
You can enter a city name to check the current weather.

## Features
- Search by city name
- Real-time weather info using OpenWeatherMap API
- Mobile responsive design

## How to use
1. Open the website.
2. Enter a city name.
3. Click "Check the weather".

※ API key is hidden for safety.
